# HORK 1.0 (Build 8)

This focused interface update improves the empty states in Pricing and Barcoding.

- Keeps the Pricing guidance panel directly beneath the stock chooser instead of leaving a large empty gap.
- Gives Barcoding a balanced full-width empty state when no items are waiting.
- Hides the unrelated sample-label preview when the active barcode queue is empty.
- Keeps barcode format and label-design controls available in a clean, uncluttered action row.
- Preserves the expandable label studio whenever stock is available.
