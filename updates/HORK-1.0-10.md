# HORK 1.0 — Build 10

This update improves reliability on both Macs and expands barcode support.

- Restores the same signed-in company inventory on a second Mac instead of opening an empty local shell.
- Reduces repeated background work that could cause slow menu changes, beachballs and uneven table scrolling on the Intel MacBook Air.
- Lets custom barcode formats contain up to 13 letters or digits on the 38 mm label.
- Keeps the complete 13-character number visible within the label margins and automatically uses the widest Code 128 module size that safely fits.
- Retains standard EAN-13 validation, quiet zones and print-safe sizing.

After installation, HORK restarts automatically. Existing company data, licences and sign-in details are not removed.
