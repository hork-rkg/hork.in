# HORK 1.0 (Build 21)

Build 21 makes Trade and invoice entry substantially more responsive and brings the four voucher screens into one consistent, compact workflow.

- Prevents repeated invoice-window layout calculations that caused cursor, menu and scrolling delays.
- Improves Sales, Purchase, Sales Return and Goods Return layouts, item lookup and selected-item details.
- Protects manual changes to invoice dates, voucher numbers and item prices with the signed-in user's HORK password.
- Improves customer and supplier tables, name formatting, actions, status dates and print/export options.
- Refines Inventory editing, product photos and colour selection while removing irrelevant size and stock-level controls.
- Streamlines Pricing and Barcoding tools and removes deferred Version 2 navigation items.
