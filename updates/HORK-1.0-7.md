# HORK 1.0 (Build 7)

This update improves speed, reliability, and everyday workflows across HORK.

- Adds a real post-sign-in preparation screen that securely syncs cloud data, loads stock, prepares item images, and opens the workspace only when ready.
- Improves scrolling performance in Inventory, Pricing, and Barcoding, including precomputed rows and cached thumbnails.
- Adds privacy-safe diagnostics with a manual “Send diagnostics” option and optional follow-up after an unexpected close.
- Improves invoice completion so printing closes the preview and prepares the next sale cleanly.
- Refines sales history, invoice entry, barcode design, pricing, stock totals, customer matching, and single-location behaviour.
- Includes stability improvements for older Intel Macs running macOS Monterey 12.
