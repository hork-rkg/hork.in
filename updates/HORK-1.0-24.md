# HORK 1.0 — Build 24

Build 24 makes pricing and barcode maintenance clearer, faster, and reversible.

- The Pricing ledger now uses a cleaner, properly aligned table with the pricing inspector kept on the right.
- Existing prices can be removed or recalculated, including bulk changes for selected stock.
- Repriced items can be sent directly back to Barcoding so fresh labels show the new price.
- Existing barcode numbers are preserved for price-only label reprints, while an explicit reassign action can generate a new code when required.
- Pricing and Barcoding data is prepared during the post-sign-in loading stage to reduce page-opening delay and improve scrolling and selection responsiveness.
- Inventory pricing and barcode queues refresh immediately after changes, without losing the existing stock workflow.

This update does not erase existing business records during installation.
