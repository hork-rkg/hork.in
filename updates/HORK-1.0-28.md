# HORK 1.0 (28)

Build 28 improves employee profiles and sales-return handling.

- Employee profiles now include an address and a direct way to set or update monthly salary.
- Sales invoices offer a prefilled sales-return action linked to the original invoice.
- Reversing an invoice no longer leaves its original payment balance presented as collectible.
- Stock is reduced when a sale is filed and restored when a linked sales return is filed; opening a return draft does not change stock.

Existing business records remain in place when the app updates.
