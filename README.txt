HORK brand files
================

LOGO
  hork-logo.svg        The borderless mark, full colour, transparent background.
                       Vector — use this one wherever you can. It stays sharp
                       at any size, from a favicon to a shop hoarding.
  hork-logo-mono.svg   The same mark in a single colour. It takes whatever
                       colour it is placed in, so it works for a rubber stamp,
                       an embroidery file, a one-colour print, or white on a
                       dark background.
  hork-logo-1024.png   Ready-made pictures, transparent background, for places
  hork-logo-512.png    that will not accept an SVG — WhatsApp Business, most
  hork-logo-256.png    marketplace seller profiles, Word, PowerPoint.
  hork-logo-128.png    Pick the size nearest to how big it will appear, and
  hork-logo-64.png     never scale a PNG up.
  hork-logo-32.png

WORDMARK (mark plus the word HORK, side by side)
  hork-wordmark.svg    For a letterhead, an email signature, or the top of a
  hork-wordmark.png    web page, where the mark alone would not say the name.

WEBSITE
  index.html           The hork.in holding page.
  privacy.html         Public privacy policy for the Mac App Store listing.
  support.html         Public support and account-deletion help page.
  favicon.svg          Browser-tab icon shared by the public pages.
  hork-logo.svg        Header logo shared by the public pages.
  hork-mark-flat.png   Flat copper H used by the holding page.
  omira-wordmark.png   Gold Omira retail wordmark.
  textile-house-hero.png
                       Cultural textile-house background for the holding page.
                       HORK at the top, then a card each for Hari Om Raj Kumar
                       (wholesale) and Omira (retail), then the contact address.

                       The holding page is self-contained. Privacy and support
                       use the two shared SVG files listed above.

  To put the App Store-ready site up, upload index.html, privacy.html,
  support.html, favicon.svg, favicon-180.png, hork-logo.svg,
  hork-mark-flat.png, omira-wordmark.png and textile-house-hero.png together
  into the web root of hork.in. The public URLs must be exactly:
    https://hork.in/privacy.html
    https://hork.in/support.html

  The page asks Google Fonts for its serif (Cormorant Garamond). That is the
  one thing it fetches from outside itself, and it is not required: if the
  font does not load, the page falls back to the best serif already on the
  reader's machine and still looks right. Nothing breaks, nothing shifts.

  them will sit beside it without clashing.
